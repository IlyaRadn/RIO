# Рабочее место сотрудника: Альтернативные расчеты

Интерактивный роадмап проекта на 3 квартал. Публикуется через GitHub Pages.

## Онлайн
https://ilyaradn.github.io/RIO/

## Как вносить изменения
Всё в одном файле `index.html`. Данные — в теге `<script>` внизу файла:
- `rows`     — задачи и спринты (Gantt): поля `devS/devE` (старт/конец разработки), `ba/dev/qa` (ЧД по этапам), `qaLater` (тест в Q4).
- `planInc`  — плановая загрузка по спринтам (для графика ёмкости).
- `disc`     — нагрузка по направлениям (`q3`/`q4`).
- `q4`       — бэклог 4 квартала.

Отредактировал `index.html` → сохранил → `git commit` + `git push` → сайт обновится за ~1 минуту.
